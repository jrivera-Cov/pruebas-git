## 1. Objetivo
Asegurar la correcta creación de cuentas, asignación de licencias y configuración de equipos, incluyendo la instalación de software básico y específico por área.

## 2. Alcance
Aplica al personal de Soporte Técnico encargado de gestionar usuarios en Active Directory, Google Workspace y la preparación de equipos asignados.

## 3. Responsables
- Recursos Humanos: Proporcionar datos completos del colaborador.
- Soporte Técnico: Ejecutar el procedimiento y validar la configuración técnica.

## 4. Herramientas y Recursos
- Sistema de tickets
    - JIRA
- Active Directory
- Google Workspace (Administrador)
- Script corporativo de instalación básica
- Equipo de cómputo asignado

## 5. Procedimiento
### 5.1 Apertura del Ticket
- Registrar la solicitud en el sistema de tickets con los datos obligatorios:
    - Nombre completo
    - Correo personal
    - ID de empleado
    - Celular
    - Puesto y área
    - Manager
    - Fecha de ingreso
    - Departamento
    - Herramientas y permisos requeridos

### 5.2 Verificación de Datos
Confirmar que la información esté completa y correcta. En caso de error, solicitar corrección antes de continuar.

### 5.3 Creación de Usuario en Active Directory
- Crear cuenta con nombre de usuario y contraseña inicial.
- Asignar unidad organizativa, grupos de seguridad y permisos.

### 5.4 Creación de Usuario en Google Workspace
- Crear correo institucional.
- Asignar licencias necesarias.
- Configurar grupos de correo, alias y unidades organizativas.

### 5.5 Instalación de Software
#### 5.5.1 Paquete Básico (para todos los usuarios)
El script corporativo instala automáticamente:
- LibreOffice
- Adobe Reader
- Dell Command
- AWS VPN Client
- Google Drive
- TeamViewer
- Java
- Google Chrome
- WinRAR
- Antivirus Kaspersky

#### 5.5.2 Aplicaciones por Área
| Área |	Aplicaciones adicionales |
|------------|---------------------------|
| Ventas y Crecimiento |	Sin Office	|
| Legal |	Office, Adobe Acrobat |
| Operaciones |	Office |
| Mesa de Control |	Office |
| Finanzas / Contabilidad |	Office, Contafiscal Dynamics |
| Tesorería |	Office |
| SLT |	Office |	
| Core Banking | Oracle, SQLdbx	| 

### 5.6 Preparación del Equipo
- Instalar aplicaciones según área.
- Ejecutar Diagnostics para validar funcionamiento.
- Verificar conectividad, inicio de sesión y rendimiento.

### 5.7 Entrega y Validación
- Entregar equipo con credenciales iniciales y responsivas.
- Acompañar al usuario en la primera sesión para validar accesos.

### 5.8 Cierre del Ticket
- Registrar todas las acciones realizadas.
- Marcar la solicitud como Completada.

## 6. Notas y Consideraciones
- El usuario puede cambiar su contraseña al primer inicio de sesión en el onboarding.
- Cumplir con políticas de seguridad de la información vigentes.
- Mantener registros actualizados para auditorías internas.
